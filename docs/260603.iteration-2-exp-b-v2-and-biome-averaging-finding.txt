OBJECTIVE
--------------------------------------------------------------------------------

Experiment B v1 (raw inverse-frequency class-balanced loss) produced
chunks with massive Breakable over-prediction (65 to 75 percent of
every chunk), documented in
docs/260602.iteration-2-exp-b-class-balanced-results.txt. The
proposed remediation was to replace the raw inverse with its square
root, compressing the weight dynamic range from 2487:1 to
approximately 50:1.

This report documents what v2 actually produced. Three things to
establish: (1) per-chunk qualitative inventory; (2) head-to-head
comparison among Iteration 1, v1, and v2; (3) a new structural
finding about how the unconditional model handles a multi-biome
training set. The finding closes Experiment B and motivates the
biome-conditional generation work documented as Experiment D in
docs/260602.iteration-2-plan.txt Part 5.

PART 4: THE BIOME-AVERAGING FINDING
================================================================================

8 of the 10 v2 chunks have a near-continuous horizontal Breakable row
in the upper portion (rows 1 to 3). Investigation traced this pattern
to a property of the training data:

    Level distribution of Breakable in the top 3 rows (computed by
    counting characters in rows 0 to 2 of each .txt file):

      Level           Top-3-row tiles    Empty    Breakable
      --------------  -----------------  -------  ----------
      mario-1-1            609            606         0
      mario-1-2            477            341       132
      mario-1-3            453            448         0
      mario-2-1            594            591         0
      mario-3-1            594            590         0
      mario-3-3            450            445         0
      mario-4-1            669            666         0
      mario-4-2            564            403       155
      mario-5-1            597            594         0
      mario-5-3            453            448         0
      mario-6-1            555            552         0
      mario-6-2            648            645         0
      mario-6-3            498            489         0
      mario-7-1            531            527         0
      mario-8-1           1122           1119         0

Only mario-1-2 and mario-4-2 contain Breakable tiles in the top 3
rows. Both are the only UNDERGROUND levels in the Super Mario Bros
VGLC corpus. The cave ceiling in the underground biome is encoded
as a long horizontal Breakable run, exactly the pattern visible in
every v2 generated chunk.

Quantitatively: of the 2518 training chunks, approximately 291 come
from underground levels (158 - 28 + 1 = 131 chunks from mario-1-2
and 187 - 28 + 1 = 160 chunks from mario-4-2), which is 11.5 percent
of the training set. The remaining 88.5 percent of chunks come from
overworld and treetop levels and have no top-row Breakable.

The unconditional generative model learns to produce samples drawn
from the AVERAGE of the training distribution. The model has no
input signal indicating which biome the current sample should belong
to. So the most distinctive structural feature of the underground
biome (the cave ceiling) gets averaged into every generated chunk
with a probability roughly proportional to the underground biome's
frequency in the training set.

This is independent of the class-balanced loss. The same biome
averaging happens in Iteration 1 (unweighted) and Experiment B v1.
The reason it became VISUALLY DOMINANT in v1 is that v1 amplified
Breakable predictions broadly. The reason it became VISUALLY CLEAN
in v2 is that v2's moderated weighting allowed the model to express
the cave-ceiling pattern correctly (long horizontal Breakable rows)
without spamming Breakable elsewhere. In other words: v2 is a better
class-balanced model, and as a result the cave-ceiling biome-bug is
now clearly visible instead of being buried under brick spam.


================================================================================
PART 5: WHY CLASS-BALANCED LOSS CANNOT FIX BIOME AVERAGING
================================================================================

Class-balanced loss adjusts the per-pixel gradient contribution
based on the tile type at that pixel. It does not provide the model
with any information about WHICH BIOME the current training sample
comes from. The model has no mechanism to learn that "I should
produce cave ceilings ONLY when generating underground chunks" -
because the model has no concept of "underground chunks" vs
"overworld chunks." The only thing it can learn is the marginal
distribution of tile types in the training set.

A model trained on a multi-biome corpus without biome conditioning
will, in general:

  - Reproduce the most common single-biome feature with the
    frequency of that biome in the training set.
  - Combine incompatible features from different biomes in the same
    output (e.g., cave ceiling + outdoor pipes).
  - Be unable to generate cleanly-typed samples for any specific
    biome on demand.

These are not bugs in the model; they are consequences of the
unconditional formulation. Class-balanced loss, sqrt weighting,
Effective Number of Samples weighting, and focal loss are all
loss-shape modifications and none of them changes this property.

The fix is structural: the model must accept a biome label as
additional input, the training loop must provide the correct biome
label for each chunk, and the inference loop must accept a biome
label from the caller. This is conditional generation, and it
matches Experiment D as planned in
docs/260602.iteration-2-plan.txt Part 5.

PART 6: CLOSING EXPERIMENT B AND MOTIVATING EXPERIMENT D
================================================================================

Experiment B is concluded with the following results:

  - v1 (raw inverse-frequency): FAILED at the qualitative bar
    (rare-class spam dominates). Documented in
    docs/260602.iteration-2-exp-b-class-balanced-results.txt.
  - v2 (sqrt inverse-frequency): PARTIAL SUCCESS. Best variant of
    the three CFM loss formulations tested. Resolves the
    DiscontinuousGround failure mode that dominated Iteration 1.
    Surfaces a previously-hidden structural limitation (biome
    averaging) that is not fixable within the class-balanced loss
    framework.
  - The sqrt variant is retained as the default loss in
    CfmTrainingLoop.cs going forward. Future experiments can build
    on top of v2 rather than reverting to unweighted MSE.

The three checkpoints are preserved as ablation evidence:

  unet-baseline-checkpoint.bin           Iteration 1 unweighted
  unet-class-balanced-checkpoint.bin     Exp B v1 raw inverse
  unet-sqrt-balanced-checkpoint.bin      Exp B v2 sqrt inverse (current)

Next experiment: Experiment D (conditional generation by biome
label), as planned in docs/260602.iteration-2-plan.txt Part 5.
Specific changes anticipated:

  1. Assign a biome label to each VGLC level (overworld, underground,
     treetop, special) based on level name pattern.
  2. Add a biome-embedding lookup table to UnetBaseline that maps
     the biome label to a learnable vector. Concatenate the biome
     embedding with the time embedding before injecting into each
     ResidualConvBlock.
  3. Pass the biome label as an additional parameter through
     CfmLossComputer.ComputeWeightedLoss and EulerOdeSolver.Solve.
  4. Modify the training loop to look up each chunk's biome label
     from its source level when assembling the batch.
  5. Modify the generate entrypoint to accept a biome label
     argument (e.g., --biome overworld).
  6. Re-train with the same hyperparameters as v2 (sqrt loss,
     20000 steps, BaseChannels 64, BatchSize 32). Generate per-biome
     samples and verify the cave-ceiling pattern appears only in
     underground generations.

Expected outcome (testable): biome-conditional generation produces
clean per-biome samples. Specifically: generations with
biome=overworld should have no Breakable in the top 3 rows;
generations with biome=underground should have continuous Breakable
in the top 3 rows; generations with biome=treetop should have
elevated brick platforms with sky above and below them.

If verified, Experiment D closes the qualitative gap that motivated
Iteration 2 and produces samples suitable for the TCC manuscript
Chapter 4 result section. If unverified, the next experiment would
be Experiment C (discrete flow matching).
