The entry point performs five verification steps:

    1. Loads every VGLC Super Mario Bros Processed .txt file
    2. Extracts sliding-window chunks of shape (14, 28)
    3. Converts first chunk to one-hot tensor of shape (14, 14, 28)
    4. Converts all chunks to batch tensor of shape (N, 14, 14, 28)
    5. Round-trips tensor back to TileMap back to ASCII text

PART 3: REMAINING WORK FOR ITERATION 1
================================================================================

Five components remain before Iteration 1 can be declared complete.

3.1 UnetBaseline class
    Composes SinusoidalTimeEmbedding, ResidualConvBlock, DownsampleBlock,
    and UpsampleBlock into the full encoder-decoder-with-skip-connections
    U-Net. Must accept tensor input of shape (N, 14, 14, 28) and time
    tensor of shape (N,), and return predicted velocity field of shape
    (N, 14, 14, 28). Estimated effort: 1 day.

3.2 Evaluation metrics assembly c2-pcg.flow-matching-eval
    Implements the five metrics specified in the Iteration 1 plan:
    local constraint violation rate, ground continuity score, visual
    diversity score, generation speed measurement, training loss
    accumulator. Estimated effort: 1 day.

3.3 CFM training loop assembly c2-pcg.flow-matching-training
    Implements the linear-interpolation Conditional Flow Matching
    training loop, Adam optimizer integration, model checkpoint
    writer and reader, per-step loss logger. Estimated effort: 2 days.

3.4 Euler ODE solver assembly c2-pcg.flow-matching-inference
    Implements the iterative Euler integration from random noise to
    generated map, plus a MapGenerator orchestrator. Estimated
    effort: 1 day.

3.5 c4 subcommand integration
    Extends the existing c4-cmd.pcg-flow-matching assembly with two
    additional entry points: PcgFlowMatchingTrainEntryPoint and
    PcgFlowMatchingGenerateEntryPoint. Updates the .csproj file with
    the four new c2 assembly references. Estimated effort: 0.5 day.

3.6 First training run
    Runs training on the company devbox with 3x RTX 3090 Ti for 5000
    steps, batch size 32. Produces a model checkpoint and 100 sample
    generated chunks. Computes all five evaluation metrics.
    Estimated effort: 2 days (including monitoring and result
    documentation).

Total estimated effort to complete Iteration 1: 7.5 working days.

PART 4: REMAINING WORK FOR ITERATION 2
================================================================================

Iteration 2 improves the baseline based on Iteration 1 empirical findings.

4.1 Architecture adjustments
    Tune U-Net depth (add 3rd or 4th downsampling level with input
    padding to 16x32). Tune channel progression. Adjust ResidualConvBlock
    internals if training stability issues appear.

4.2 Optimal Transport probability paths
    Replace linear interpolation with Optimal Transport trajectories for
    potentially straighter velocity fields and faster sampling.

4.3 Sinusoidal time embedding injection via AdaGN
    Replace simple additive time bias with Adaptive Group Normalization
    that modulates both scale and shift per channel based on time.

4.4 Hyperparameter exploration
    Run 3 parallel experiments on the 3 devbox GPUs with different
    learning rates, batch sizes, Euler step counts (5, 10, 20, 50).
    Document results for each configuration.

4.5 TCC Chapter 4 intermediate section
    Document Iteration 2 architecture changes and their empirical
    justification in comparison to Iteration 1 baseline.

Estimated effort: 3 weeks (accounting for experiment iteration time).
